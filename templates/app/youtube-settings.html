Autenticação

Configure suas credenciais do Google Cloud para acessar a YouTube API.

Como configurar:

  1. Vá para Google Cloud Console
  2. Crie um novo projeto
  3. Habilite a YouTube Data API v3
  4. Crie uma credencial OAuth 2.0 do tipo "Aplicativo da Web"
  5. Adicione a Redirect URI abaixo em "URIs de redirecionamento autorizados"
  6. Copie o Client ID e Client Secret abaixo
Encontrado em: Google Cloud Console → Credenciais → OAuth 2.0
⚠️ Obrigatório apenas na primeira configuração. Depois disso, fica em branco por segurança e é preservado automaticamente ao salvar outros campos — só preencha aqui se quiser trocá-lo.
Necessária apenas para operações de leitura sem autenticação do usuário
Precisa ser idêntica, caractere por caractere, à URI cadastrada em "URIs de redirecionamento autorizados" no Google Cloud Console — inclusive "localhost" vs "127.0.0.1" contam como diferentes.
